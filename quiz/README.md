# Квиз — мини-приложение для VVelcom

Викторина «Автомобили, История, ИТ, Фильмы, Комиксы» как мини-приложение бота VVelcom, серверная часть на Yandex Cloud Functions и **раунды для групп**: бот присылает в чат сообщение с кнопкой «Играть в раунд», у всех игроков одни и те же вопросы, а таблица результатов в этом сообщении обновляется после каждой сыгранной партии.

- `web-app/` — статический фронтенд (HTML/CSS/JS без зависимостей и сборки). Хостится в Yandex Object Storage или на любом HTTPS-хостинге.
- `cloud-function/` — облачная функция Node.js 22 без зависимостей: результаты, рейтинг, раунды и ответы бота в чате.
- `scripts/` — сборка банка вопросов (`scripts/src/<категория>.json` → `questions.json`).
- `tests/` — тесты.

## Как играть

В мини-приложении (или раундом в чате) выбирают:

- **категории** — отметками или «Выбрать все»;
- **сложность** — Лёгкая / Средняя / Сложная / Смешанная (40 % лёгких, 40 % средних, 20 % сложных). У каждого вопроса есть свой уровень, и из банка берутся вопросы именно этого уровня; если в категории их не хватает, добираются ближайшие по сложности;
- **число вопросов** — 15, 20 или 30. Категории представлены поровну.

На ответ — 20 секунд. Очки: 10 / 20 / 30 за верный ответ лёгкого / среднего / сложного вопроса и до +50 % за скорость. Рейтинг — сумма десяти лучших партий игрока.

## Раунды в группе

1. В группе (или в личном чате с ботом) отправьте `/quiz` — бот пришлёт кнопки: категории с отметками, сложность, число вопросов, «Создать раунд». Всё состояние выбора хранится в `callback_data`, на сервере до создания раунда ничего не сохраняется.
2. Сообщение превращается в карточку раунда с кнопкой **🎮 Играть в раунд**. Кнопка `web_app` несёт `start_param` вида `r_<id раунда>` (расширение платформы, см. «Параметр запуска» в `docs/api/bot-api.md`).
3. Приложение открывается сразу на раунде. `start_param` приходит в **подписанном** `initData`, функция читает его оттуда, а не из запроса, поэтому игрок не может подменить раунд. Вопросы раунда фиксируются при создании (по `seed`), у всех игроков один набор; варианты ответов перемешиваются у каждого свои.
4. У каждого игрока в раунде **одна попытка**. После результата функция вызывает `editMessageText` у карточки: в ней место, имя, очки и «верно/всего». К таблице прикладывается кнопка «📣 В ленту».
5. Раунд принимает результаты `ROUND_HOURS` часов (24 по умолчанию). Когда время вышло, ближайшее обращение к раунду (открытие или попытка записать результат) переписывает сообщение в «🏁 Квиз-раунд завершён» с итогами и убирает кнопку. Проверка ленивая: фоновых таймеров нет. Если нужно закрывать сразу по сроку, добавьте триггер по расписанию.

Раунд можно создать и из мини-приложения кнопкой «🧠 Раунд для чата» (когда оно открыто из чата кнопкой `web_app`): сообщение уходит через `answerWebAppQuery`. Таблица в нём обновляется, если платформа вернула в ответе `chat_id` и `id` сообщения (функция их запоминает); иначе раунд работает, но карточка не перерисовывается — в этом случае используйте `/quiz`.

## Команды бота

`/start`, `/play` — кнопки «Играть» и «Раунд для чата» · `/quiz` — создать раунд · `/top` — рейтинг · `/stats` — моя статистика · `/name Имя` — имя в рейтинге · `/help`.

## Где хранятся данные

Папка подключённого к функции хранилища (`QUIZ_STORAGE_DIR`, по умолчанию `/function/storage/quiz-vv-app`):

```
players/<userId>/player.json                 партии, лучшие результаты, точность по категориям
rounds/<roundId>/round.json                  настройки раунда, id вопросов, чат и сообщение для обновления
rounds/<roundId>/results/<userId>.json       результат одного игрока (отдельные файлы: одновременные записи не затирают друг друга)
```

Подключите бакет Object Storage в настройках функции («Хранилище» → точка монтирования с именем из `QUIZ_STORAGE_DIR`). Рейтинг считается по `userId` из подписанного `initData`: id постоянный, история сохраняется при смене имени.

## Развёртывание

1. Создайте бота в [@VVbotMother](https://uvvel.com/@VVbotMother) (`/newbot`), получите токен `vv_…`. Токен выпущен до появления мини-приложений? Перевыпустите его (см. документацию).
2. Соберите вопросы: `node scripts/build-questions.js` (кладёт `questions.json` и `quiz-rules.js` в `cloud-function/`, `questions.json` в `web-app/data/`).
3. Создайте облачную функцию: Node.js 22, обработчик `index.handler`, таймаут 15 с. В корень архива положите `index.js`, `stats.js`, `quiz-rules.js`, `questions.json`, `package.json`. Подключите хранилище.
4. Переменные окружения (`cloud-function/.env.example`):

   | Имя | Назначение |
   |---|---|
   | `VVELCOM_BOT_TOKEN` | токен бота |
   | `ALLOWED_ORIGINS` | origin фронтенда без пути, через запятую |
   | `GAME_URL` | HTTPS-адрес `index.html` (кнопки «Играть») |
   | `VVELCOM_WEBHOOK_SECRET` | секрет webhook, например `openssl rand -hex 24` |
   | `QUIZ_STORAGE_DIR` | папка подключённого хранилища |
   | `ROUND_HOURS` | сколько часов раунд принимает результаты (24) |
   | `QUIZ_BOT_LINK` | ник бота для приглашений в ленте, например `@quiz_vvbot` |

5. Загрузите `web-app/` (без `tests/`, если появятся) в бакет, в `config.json` укажите `backendUrl` — URL функции.
6. Подключите webhook. Нужны и сообщения, и нажатия кнопок:

```bash
curl -sS -X POST "https://apibots.vvelcom.online/bot${VVELCOM_BOT_TOKEN}/setWebhook" \
  -H 'Content-Type: application/json' \
  -d "{\"url\":\"https://functions.yandexcloud.net/ВАШ_ID?mode=webhook\",\"secret_token\":\"${VVELCOM_WEBHOOK_SECRET}\",\"allowed_updates\":[\"message\",\"callback_query\"]}"
```

7. Чтобы бот отвечал на `/quiz` в группе, добавьте его в группу; команды вида `/quiz@ник_бота` доставляются без режима «Видит все сообщения».

Проверка: `GET` на URL функции возвращает `{"service":"quiz","configured":true,…}`.

> Время ответа приходит с клиента и поэтому годится для дружеского соревнования, но не для публичного рейтинга с призами. Сервер проверяет, что ответы относятся к настоящим вопросам (в раунде — именно к вопросам этого раунда), не дублируются, и считает очки сам; слишком быстрые партии (в среднем быстрее 1,2 с на вопрос) сохраняются, но в рейтинг не попадают.

## Как добавить вопросы

Добавьте строку в конец `scripts/src/<категория>.json`: `[сложность 1–3, "вопрос", "верный ответ", "неверный", "неверный", "неверный"]` и запустите `node scripts/build-questions.js`. Верный ответ всегда первый — в игре варианты перемешиваются. Строки **только добавляйте в конец**: id вопроса — это категория и номер строки. Новую категорию добавляют в `CATEGORIES` в `web-app/quiz-rules.js` (только в конец списка: порядок задаёт биты маски категорий в кнопках чата) и файлом в `scripts/src/`.
