# Бот-администратор пространства

Показывает, как бот управляет пространством: встречает новых участников, добавляет их в группы,
создаёт группы с разделами и выполняет команды владельца. Без сторонних библиотек, Node.js 20.6+.

## Подготовка

1. Создайте бота в [@VVbotMother](https://uvvel.com/@VVbotMother) и добавьте его в своё пространство.
2. В пространстве откройте «Боты» → значок настроек у бота → «Права бота» и включите нужные права:
   - «Участники пространства» — для `/kick`;
   - «Группы пространства» — для `/groups`, `/newgroup`, `/rename` и добавления в группы;
   - «Писать участникам» — чтобы бот мог первым написать новому участнику.
3. `id` пространства бот видит в `chat.space_id` любого сообщения из этого пространства. Можно также
   временно вывести его в консоль из любого update.

```bash
cp .env.example .env             # Windows: copy .env.example .env
npm start
```

## Что умеет

- Новый участник пространства (update `space_member`) получает приветствие в личку, и его добавляют
  в группы из `WELCOME_GROUP_IDS`.
- Изменения состава групп, где бот админ (update `chat_member`), выводятся в консоль.
- Команды владельца бота в личном чате: `/groups`, `/newgroup Название`, `/rename <chat_id> Название`,
  `/kick <user_id>`.

`chat_member` и `space_member` приходят, только если явно перечислить их в `allowed_updates`, как в Telegram.
Подробнее — раздел «Бот — администратор пространства» в документации Bot API.
