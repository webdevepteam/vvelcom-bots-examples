# Sudoku Web App 1.4

Содержимое этого каталога загрузить в Yandex Object Storage. В `config.json` заменить `backendUrl` на HTTPS URL Yandex Cloud Function. В браузер нельзя помещать секретный `VVELCOM_BOT_TOKEN`.

Управление: один тап по клетке и символу либо удержание/перетаскивание; двойной быстрый тап по заполненной игроком клетке — ластик. «Начать сначала» восстанавливает текущее поле, таймер при этом идёт и сохраняется. «Заметки» — режим маленьких кандидатов в клетках, выключите его перед окончательным ответом.

После завершения игра предлагает передать результат в чат VVelcom. Для автоматической отправки необходим подписанный `initData.query_id`; при его отсутствии можно воспользоваться обычной функцией «Поделиться».

## Работа без интернета

Мессенджер сам хранит копию игры (см. `docs/mini-app-offline.md`). Для этого:

- SDK лежит рядом (`vvelcom-web-app.js`, копия `server/bot-service/public/vvelcom-web-app.js`), а не грузится с чужого домена: иначе офлайн не сохранился бы. При обновлении SDK перекопируйте файл.
- Все файлы игры — с того же домена; `data/puzzles.json` и `config.json` кешируются, когда игра открыта онлайн.
- Хостинг (Object Storage) должен отдавать `Cache-Control: no-cache` и `ETag`/`Last-Modified` (Object Storage отдаёт ETag сам; `Cache-Control` задаётся метаданными объектов при загрузке). Без этого обновления дойдут до копии не быстрее чем через 6 часов.
- Отправка результата и «в ленту» без сети не работают; прогресс и статистика лежат в `localStorage` и остаются.
