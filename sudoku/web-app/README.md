# Sudoku Web App 1.4

Содержимое этого каталога загрузить в Yandex Object Storage. В `config.json` заменить `backendUrl` на HTTPS URL Yandex Cloud Function. В браузер нельзя помещать секретный `VVELCOM_BOT_TOKEN`.

Управление: один тап по клетке и символу либо удержание/перетаскивание; двойной быстрый тап по заполненной игроком клетке — ластик. «Начать сначала» восстанавливает текущее поле, таймер при этом идёт и сохраняется. «Заметки» — режим маленьких кандидатов в клетках, выключите его перед окончательным ответом.

После завершения игра предлагает передать результат в чат VVelcom. Для автоматической отправки необходим подписанный `initData.query_id`; при его отсутствии можно воспользоваться обычной функцией «Поделиться».
